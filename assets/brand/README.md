# 掠影 Glimpse

标记由两张掠过视野的光页构成，呼应照片、视频与快速翻阅。使用本项目绘制的几何图形，不依赖图标字体或外部品牌素材。

- 主色：浅紫 `#BAA4F5`；次色：紫灰 `#7E67BA`；图标底色：`#1C1B23`。
- `glimpse.svg` 为可缩放母版，`glimpse.png` 为 256px 透明圆角图标。
- `glimpse.ico` 包含 16/24/32/48/64/128/256px，嵌入 Windows EXE；运行时窗口使用同源图标。
- 应用内标记由 `src/branding.rs` 按逻辑坐标绘制；标题栏、侧栏、设置页和系统菜单使用统一名称。
- 通过 `python tools/create_brand_assets.py` 重新生成 PNG/ICO，无第三方绘图依赖。

存储目录、数据库、实例协议和可执行文件名保留原有标识，避免改名造成数据迁移或单实例不兼容。
