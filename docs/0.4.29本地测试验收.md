## 布局安排与实际改动

| 位置 | 内容 | 原因 |
| --- | --- | --- |
| 第一排左侧/中部 | 品牌、后退/前进/上级、目录路径、搜索、刷新、打开目录 | 同属于导航和位置操作。 |
| 第一排右侧 | CPU/内存/读写速度，最小化/最大化/关闭 | 性能数字是只读状态，不作为设置按钮；窗口按钮仍在右上。 |
| 第二排最左 | 展开/收起目录菜单 | 菜单控制与下方内容区相邻，不占用标题导航位置。 |
| 第二排中间 | 全部/图片/视频、收藏、排序、分组、缩略图大小、全选 | 浏览时经常调整，保持直接可见。 |
| 第二排最右 | 统一设置入口 | 固定位置；低频设置通过现有分类面板进入，窄窗下仍保留该入口。 |

统一设置仍使用已有的常规、外观、视频、字幕、快捷键和系统集成分类，没有增加新功能或改动设置内容。中部控件在窄窗自然换行，设置入口保留右侧位置，不依赖一串居中的零散图标。

普通产品源码仅改browser_ui.rs的位置与分栏；新增显式design-smoke点击/几何记录用于验证。Cargo版本递增，依赖锁定版本不变。播放、解码、缓存、尺寸反馈、generation/文件版本、画质和有界预算未修改。当前原生Rust/egui/glow及内嵌libmpv GPU保持；未操作真实图库删除/旋转或关闭用户实例。
