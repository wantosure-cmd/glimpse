# 0.4.40 吸顶目录条按方向跳转媒体位置

2026-10-28。应用及安装器0.4.40，程序SHA256 `7eeab538ae4dd450797ee7dc1fa98ff7f5574669b2df1c2c733a077b601948cc`，168项生产输入。仅本地测试；实际便携/源码/安装状态以 `dist/0.4.40-local-test-20261028-media-jump/delivery.json` 及 `verification/index.json` 为准；旧0.4.39及以下冻结。

吸顶目录条最右增加方向按钮，面包屑横向滚动区域独立预留按钮宽度，长路径不把按钮挤出屏幕。默认向下，列表收到向下滚轮后为向下，向上滚轮后为向上；点击按当前排序/筛选后的分组顺序，跳过空目录，定位该方向有媒体的目录。图片筛选不会跳到仅含视频的组；方向无目标时禁用，不绕回。目录及祖先折叠时先展开再定位，图片尺寸尚在读取时继续沿用已有定位锚点跟随布局，不解码全库来找目标。

向上时若当前媒体组的开头仍在上方，先定位当前组开头，再次点击可去前一组；已经对齐当前开头则直接找前一组，避免重复点击卡在原位。跳转不会改变原浏览根、排序、筛选或选中状态。只有输入路由放行到列表的垂直滚轮更新方向，详情缩放/视频快进、设置、菜单、目录浮层滚动不改变它。程序跳转自身不反转方向。

跳转索引由既有后台准备线程从当前MediaView构建，元数据或折叠更新重用同一索引；UI按目录序号二分查询，不每帧遍历整库或读取磁盘。新准备结果尚未发布时按钮暂不可用，防止按旧筛选跳错；generation、文件版本和原异步任务边界保留。没有新增播放器、整库预转码或扩大像素缓存/纹理预算。
