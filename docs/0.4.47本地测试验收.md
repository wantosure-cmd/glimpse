# 0.4.47 删除后台化与紧凑播放栏

本轮针对用户指定 `dist/0.4.20/media-browser-portable` 的程序修改。该目录的程序内部版本为 **0.4.46**，SHA256 为 `7f4305e7e54189ce401172341fc7d56aef521d4fddbddb27f51da3b615bbddc5`，与自带《本轮验证.md》一致。原工作区 Cargo.toml 是0.4.18，未拿旧源码覆盖新版。

经用户明确授权，从 `https://github.com/wantosure-cmd/glimpse.git` 拉取到独立 `upstream-glimpse` 目录，基线提交 `fa3ffbd3edb6db6dac35039d933f360107ad9908`，主分支版本0.4.46。本轮仅本地修改，不提交或推送远端；原程序及正在运行的实例保留。

## 修改

- 删除任务进度改为右上角非模态提示：紧凑标题、已处理/总数、百分比和3pt细进度线。不显示遮罩、不捕获焦点或鼠标，不再以大号0%胶囊占据中央。
- 解除删除期间全局浏览锁：允许列表操作、目录切换、其他媒体详情/视频、空格暂停、详情返回和设置快捷键。必要的源文件释放阶段仍短暂禁止新播放器/动画占用，任务提交后只保护该批文件及被删除文件夹的后代。
- 缩略图后台请求继续有界，删除目标继续禁止重新打开；预加载、追加删除/旋转及自动轮播保留各自的保护。永久删除仍需独立确认，不自动降级。
- 完成/释放失败不再把已切换的详情强制跳回原媒体；完成时只刷新仍在浏览的对应根目录。
- 播放控制行从32pt内容+上下各2pt改为24pt、无上下内边距；按钮/时间/滑块同中心线，视频画布相应增高12pt。缩略图导航及图像页布局保留。
- 清理任务的输入阻挡仅用于确认阶段；后台执行和撤回倒计时允许普通浏览。
