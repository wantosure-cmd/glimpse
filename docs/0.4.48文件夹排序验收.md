# 0.4.48 文件夹跟随列表排序

基于本机0.4.47继续修改，沿用Rust/egui/glow及内嵌GPU视频。原0.4.47交付保留，不上传项目或媒体，不写入远端。

## 行为

- 列表里的文件夹现在跟随同一个排序选择和升/降序按钮：名称、修改时间、大小均生效。
- 名称使用自然排序（例如folder2先于folder10）；排序只调整同一级文件夹，父目录始终在其子树前，子树连续展示。文件仍按原有规则在各目录内排序；类型分组、折叠和详情序列保持一致。
- 按用户明确确认，文件夹大小为内部所有支持的图片和视频总字节数，包含子目录；不累计其他格式文件，不因图片/视频筛选或只看收藏而改变排序。使用当前索引快照统计，不额外扫描整库。
- 文件夹修改时间使用文件夹自身的文件系统时间，不用内部媒体的最新时间。时间未知的目录排在已知时间后，同值按自然名称和完整路径稳定排序。
- 扫描线程复用父目录枚举时已有的文件夹元数据，根目录仅额外读取一次元数据。统计、排序、树遍历和布局继续在现有后台流程执行，UI不读取磁盘元数据。
- 索引增加可空的目录修改时间字段，采用可向后兼容的附加列，保留原schema版本、媒体ID、尺寸和缩略图记录；旧版本依旧可读取。视图复用会核对目录时间和大小，避免返回旧排序。
