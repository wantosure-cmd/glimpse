# 0.4.49 详情全屏、紧凑底栏、翻页与吸顶计数（2026-11-02）

## 本轮行为

- 普通视频详情的底部区域从100pt收至64pt，包括进度控制行、缩略图及留白；控制行仍为24pt，视频缩略图24pt高、导航条最多30pt。图片详情的缩略图尺寸保留，混合媒体当前项仍居中，首末项边界不循环。
- 详情右上关闭热区为40×32pt，贴齐视口顶边和右边，保留紧凑X图标；点击返回列表，不关闭程序。纯视频全屏时同样保留右上角退出详情热区。
- 图片/视频详情左右翻页的可见底48×64pt，图标28pt，命中区64×88pt。普通模式图片/视频的翻页中心线继续相同；控件点击不再落入画面播放/暂停。
- 视频标题栏右侧新增明确的“全屏”按钮，底部全屏图标和F11进入同一个纯视频模式。隐藏标题、底栏、缩略图，视频使用整个屏幕画布；鼠标活动时短暂显示翻页及退出控件，静止2秒后隐藏。
- 按用户确认，横竖视频均按原比例完整显示，必要时保留黑边。Esc/F11或全屏按钮退出纯视频模式，保持当前媒体、播放位置和暂停状态，并恢复进入前的窗口全屏状态；返回列表或切到图片会退出纯视频模式。
- 单击视频/空格暂停、双击返回、原有右键/字幕/音量/快进路径继续使用既有输入与播放器。全屏切换不重新加载或替换播放器。
- 列表吸顶目录右侧新增当前目录的图片/视频/直属文件夹数量，与该目录普通标题行口径一致。保留多级定位、折叠、跳媒体箭头，窄窗口限制文字宽度并可悬停查看完整内容。
- 计数映射由现有准备线程从视图构建并复用，吸顶UI只做路径查找，无每帧目录扫描或文件系统IO。
