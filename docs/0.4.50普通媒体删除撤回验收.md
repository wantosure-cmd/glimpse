# 0.4.50 普通媒体删除补齐10秒撤回（2026-11-02）

核对0.4.49源码发现：文件夹删除与清理已有10秒等待，普通图片/视频的Delete和右键删除入口却直接调用执行协调器。本轮补齐普通媒体入口的撤回保护，保留后台进度提示及现有释放、版本、回收站/永久删除边界。

## 行为

- 列表勾选媒体或详情当前媒体执行删除后，先进入10秒待提交状态；右上角显示项目数、剩余秒数及“撤回”。详情和纯视频全屏中提示也可见、可点击，不加遮罩。
- 倒计时中不提交Shell删除，不因这次操作提前卸载/移走目标媒体。可以继续浏览、播放、切换目录；撤回取消整个待提交批次，不触碰目标文件。
- 删除目标和文件版本固定为点击时的快照，不因之后的勾选/目录变化改成其他文件。当前只保留一个待撤回批次，期间重复Delete不会重复提交或重新计时；批量删除使用已有多选。
- 满10秒后才进入原有后台释放/回收流程，仍等待视频、GIF、预读及缩略图源释放。撤回之后或程序退出之前尚未提交的任务不会在后台继续删除。
- 用户已在倒计时中转去其他媒体时，删除结束不会把详情跳回原目标；实际释放时恢复无关的当前详情及其播放器位置/暂停意图，保留图片缩放状态。
- 照片旋转、文件夹删除及清理避免与待提交媒体删除重叠。已有文件夹/清理10秒逻辑保留；不支持回收站时仍需另外明确确认永久删除，权限/占用/普通失败不自动降级。
- 撤回提示面板加入媒体输入排除区，点击撤回不会同时暂停视频或返回列表。
