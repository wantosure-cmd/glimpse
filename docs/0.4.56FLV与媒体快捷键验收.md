## 用户确认的快捷键

适用于当前视频详情及纯视频全屏；照片左右保留翻页。输入框、设置/菜单及聚焦控件优先处理自己的输入，不注册系统全局快捷键。

| 按键 | 行为 |
| --- | --- |
| Ctrl+↑ / Ctrl+↓ | 加速 / 减速，每次0.25倍，范围0.25–4倍 |
| 视频← / → | 后退 / 前进5秒，持续按住可重复快进退，不翻页 |
| 视频↑ / ↓ | 音量增加 / 减少5个百分点，保留原0–400%范围与静音状态 |
| 照片← / → | 上一项 / 下一项 |
| M | 视频静音 / 取消静音 |
| R | 恢复1倍速 |
| Home | 视频从头开始播放 |

空格暂停、F11全屏、Esc退出/返回及既有自定义翻页键保留。视频里的左右键按本次要求优先用于快进退；视频翻页仍可用原小键盘0/1、界面按钮，或在设置中选择PageUp/PageDown。速度显示在短提示中，非1倍时标题附带速度；切换源和重启后继续应用所选速度，播放保持音调校正。

## FLV 根因与真实验证

统一扩展名识别列表漏了flv，导致扫描阶段直接排除，未进入播放器。现增加.flv/.FLV及混合大小写识别，目录计数/视频过滤/索引/缩略图共用该分类。

生成真实FLV封装的H.264/AAC与FLV1/MP3各一份（65秒，640×360），不是只改扩展名。旧0.4.55扫描同一根目录为0；新程序在复用旧零项索引和全新索引时均为2媒体/2视频，SQLite完整性为ok。两种样本均通过原生列表封面、GPU画面、播放推进、+30秒seek后的新画面及本进程WASAPI音频会话信号，源文件前后SHA256不变。

证据：`artifacts/flv56-before-scan.json`、`flv56-after-reuse-old-zero-index.json`、`flv56-after-fresh-index.json`、`flv56-format-matrix.json`。全量生成工具增加这两种组合，不覆盖旧24项清单；可通过独立make_flv_fixture.py增加专属样本。结果不代表所有增强FLV/罕见编码或物理听感均已验证。
