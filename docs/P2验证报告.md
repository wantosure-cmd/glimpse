# P2 图片浏览验证报告

更新：2026-10-17。P2 尚未全部验收，性能结果将由实际运行补充。

## 已验证的程序

`dist/browser-preview/media-browser.exe` 是原生浏览器预览版本，默认启动进入浏览 UI。
`--open` 指定目录，`--data-dir` 隔离测试索引和配置；P0 原型需显式 `--p0`。
此目录包不是最终安装包，不能当作 P5 已交付。

## 自动测试与真实媒体

- 纯 Rust 库测试 21 项通过：自然排序、分组、generation、索引失效、重叠根目录、布局可见查询等。
- 应用模块测试 4 项通过，另有需真实原生依赖的媒体封面测试单独执行通过。
- 普通图片尊重方向与 RGB ICC，HEIC 调用 libheif；坏 ICC 回退并记录本地错误。
- MOV/AVI/3GP/MP4 的真实封面提取、尺寸、时长测试通过；这不替代完整播放器验收。

## 已修问题

图片库的 thumbnail 方法会放大小图，导致原 900×600 详情生成过大的纹理。
现在只有原图超过目标桶时才缩小，禁止放大；同一回归纹理占用从约 221MB 降为 44,260,096 字节。
这只是短流程纹理量，不是 5,000 项进程工作集。
