## 实际执行

新增 `--format-smoke 输出目录 --open 专属单文件目录 --data-dir 专属数据目录` 只读诊断。它走浏览器实际的扫描/封面任务、详情渲染、图片原像素请求、视频 Player/GL 渲染及 SeekQueue，再回到列表。每例保存列表、详情、缩放或 seek 后、返回列表四张实际原生帧缓冲截图及状态报告。它调用程序内部动作，没有移动系统鼠标或模拟物理驱动。

24 个格式用例全部通过：10 个图片、14 个视频。样本清单 `test-media/format-matrix-v1/manifest.json`；生成脚本 `tools/make_format_fixture.py`，执行/校验脚本 `tools/run_format_matrix.py`；总汇 `artifacts/p5-format-matrix.json`，各例原始输出位于其 evidence 字段。输入前后逐项 SHA256 相同。随后补入两张用户 HEIC 并分别通过，合计 26 个；见《用户HEIC样本验证.md》。它们主图均为 8-bit，已补足一个真实旋转/镜像组合的像素核对。

| 实际用例 | 验证结果 |
|---|---|
| PNG、JPEG、JPEG EXIF=2、JPEG EXIF=6 | 封面和详情四象限 RGB 与预期方向一致；EXIF=2 为水平镜像，EXIF=6 为 90° 旋转，640×480 变 480×640；原像素纹理已解码并实际绘制 |
| 无损 WebP、BMP | 实际合法格式、封面/详情的四象限像素及原像素请求通过 |
| 两页 RGB TIFF | 第一页四象限、第二页纯品红；封面和详情像素匹配第一页，原像素请求通过 |
| 普通 HEIC、合成 10-bit HEIF、iPhone 8 Plus HEIC | 三例封面、详情、原像素纹理通过；iPhone 箭头 3024×4032 实际截图向上；10-bit HEIF 明确是合成图 |
| H.264/AAC MP4、M4V、MOV | 各自封面、时长、可见播放、WASAPI 音频会话信号、暂停后 +30 秒 seek 与可见新画面通过 |
| HEVC MOV、10-bit HEVC MP4、90° 旋转 HEVC MOV | 同上；ffprobe 确认 Main10 像素格式 yuv420p10le，旋转 MOV display matrix=90°，浏览器封面和详情显示 360×640 |

| H.264/AAC MKV、VP9/Opus WebM | 两例实际文件的完整上述媒体路径通过 |

视频共有 14 个音频测量，按程序 PID 读取 WASAPI 会话，峰值约 0.0290–0.0381；没有录麦克风，不代表已验证扬声器物理听感。播放器报告输出 `libmpv`、音频 `wasapi`。本机 H.264、HEVC、VP9 报告 nvdec，MPEG-4 Part2、H.263、MJPEG 报告软件解码。都捕获到了实际视频画面。

所有视频在详情中时间先前进，再暂停并通过真实 SeekQueue 累计 +30 秒，位置到达目标附近；seek 后截图采样与之前有可见变化。封面与播放画面的 121 个空间采样点有超过 60% 保持合理对应，旋转 MOV 为 92/121，避免只凭 metadata 宽高宣称方向正确。这个检查不是逐帧精确时间戳或 seek 延迟基准。

图片四象限检查使用已知源 RGB、含方向标签的真实编码文件、原生截图及实际绘制区域坐标，容许 JPEG/渲染差异。TIFF 第二页为明显不同颜色，可检测错误读取第二页。HEIC 没有冒用四象限源参考；iPhone 箭头另经实际截图视觉确认。

## 同构建性能复测

在本机 Win10、Release、3840×2160/150% 下，5,000 个有效媒体（4,590 JPEG、300 PNG、100 HEIC、10 MP4，专属重复样本）进行两轮各 120 秒程序化滚动。新空应用缓存/已有应用缓存的 UI 回调间隔 P95 分别为 18.32/17.67ms，进程工作集峰值 216.22/162.20MiB，纹理逻辑预算约 256MiB，两轮预览失败均为 0。5,000 个文件与生成源的哈希核对通过。证据为 `artifacts/p2-scroll-format-{cold,warm}-summary.json`。

20 次新设置目录、操作系统文件缓存已热的空窗口启动：内部首次 UI 回调中位数 255ms/P95 300ms，外部 WaitForInputIdle 中位数 189.34ms/P95 244.30ms；每次实际加载包内根目录 VCRUNTIME140.dll。正常浏览器预热 15 秒后静置 30.40 秒，CPU 总增量 0.015625 秒，按 16 逻辑核归一约 0.0032%。证据为 `artifacts/p5-format-startup.json` 和 `artifacts/p5-format-idle.json`。

这些结果不等于显示器呈现、物理输入、首张媒体显示或冷启动；工作集不包含全部 GPU 显存。5,000 个样本并非全为用户 24MP 摄影原图，不能用此压力分布替代大型摄影图库验收。
