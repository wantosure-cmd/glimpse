# Raycast 风格界面重构

更新：2026-10-21。本次保留 Rust、egui/eframe 0.37、libmpv/OpenGL、SQLite 索引和现有缩略图工作线程，未引入 WebView，也未重写媒体引擎。交付为本地测试版，应用源码许可仍按之前约定暂不决定。

## 界面与使用

- 使用四级深灰背景、柔和强调色、统一线性图标、细边框与阴影。紧凑工具栏包含目录导航、路径编辑、筛选、排序、缩略图尺寸、选择与旋转；状态栏使用低对比度单行文字。
- 保留图片原始比例、尺寸先行排版、渐进缩略图、虚拟化列表、层级细线、吸顶路径和最大单列。视频时长改为右下角轻量标签；媒体选中状态使用强调色细框和线性勾选。
- 设置为独立的分类界面，而非多层长菜单。通过工具栏齿轮、右键的设置入口或 **Ctrl+,** 打开。六类为常规、外观、视频播放、字幕、快捷键、系统集成。详情页右键入口仍可打开设置。
- 外观提供紧凑间距、减少动画及鸢尾紫/暖珊瑚/雾蓝灰三个强调色。默认交互动画 160ms；减少动画会关闭界面过渡。外观与原有设置共同保存，旧配置缺少新字段时使用兼容默认值。
- **Ctrl+K** 打开命令面板，支持中文、英文别名、拼音和不连续字符的模糊匹配；上下键选择、Enter 执行、Esc 关闭。支持打开目录、刷新、筛选、排序、全选、复制路径、切换媒体、静音、加载字幕及六类设置。按上下文隐藏不可用命令，并显示当前配置的上一项/下一项快捷键。
- 快捷键只在应用内生效，不安装全局键盘钩子。命令面板不会抢普通输入框中的 Ctrl+K。设置/命令面板打开时隔离媒体的 Delete、Space、导航和悬停播放；没有添加可由误按 Enter 直接执行的删除命令。
- 原有图片/视频右键操作、多选、旋转、回收站保护、字幕、结束策略、详情缩略图与预加载均保留。没有迁移或清理用户媒体、数据库和偏好。

## 实现位置

`src/browser_ui.rs` 集中主题与主工具栏；`src/browser_icons.rs` 使用几何线条绘制图标，无额外字体图标依赖；`src/browser_workspace.rs` 实现分类设置、配置和模糊搜索；原有媒体业务仍在相应模块。新中文加入现有编译期语言目录，并更新内置中文字体子集，无运行时翻译查找或网络依赖。

`tools/run_design_smoke.py` 生成独立的公共/合成样本，使用独立实例作用域和数据目录。`--design-smoke` 是显式启用的诊断模式，事件通过原生输入入口进入；截图来自启动后的真实 egui/OpenGL 渲染缓冲。它不是网页样图，也不是物理鼠标、系统桌面截图或 Win11 实机证明。

## 视觉迭代

第一轮真实截图发现设置内容继承横向布局，弹窗超出窗口；已分别约束分类导航和内容区的纵向布局。第二轮发现新增中文不在旧字体子集及大倍率下弹窗过高；已重新生成字体子集并收紧高度。第三轮检查分类设置、命令列表、搜索、详情覆盖和较大缩放；最后使用 Release 构建重复验证，保留原始截图和每阶段状态。

缩放测试改变应用的缩放因子，使最终 pixels-per-point 对应 100%/150%/200%；没有修改用户 Windows 显示设置。不能将其等同于不同显示器之间拖动窗口或各 Windows 版本的实机 DPI 验收。

## 交付检查

交付包含便携 ZIP、带当前应用 payload 的本地安装器和源码 ZIP。`tools/verify_raycast_delivery.py` 校验 ZIP CRC、逐文件 hash、安装器内嵌 payload，并核对源码中的生产输入与实际回归构建一致；这是内容完整性检查，不是本次重新安装/卸载的系统验收。`tools/verify_source_archive.py` 从新目录解压源码，恢复固定运行库后执行 locked/offline 的全二进制编译检查；依赖使用本机已有 Rust/Cargo/MSVC 缓存，不能称为不需要开发依赖的离线构建。

原始报告和真实渲染截图另存于本轮交付目录的 `verification`，方便独立检查。源码包不包含用户媒体、索引或缓存。启动新版前请退出旧实例，避免旧实例接收打开目录请求。
