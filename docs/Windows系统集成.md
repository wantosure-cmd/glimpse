# Windows 右键菜单与单实例

此功能属于 P4，Windows 10 本机验证在推进。Win11 传统菜单位置、物理右键操作及完整系统焦点矩阵尚未验收。

## 使用方式

便携目录保留 `media-browser.exe` 与旁边的 `runtime`。启用当前用户菜单：

```powershell
Start-Process -FilePath "D:\应用\大屏媒体浏览器\media-browser.exe" -ArgumentList '--register-context-menu' -Wait
```

移除由这份程序注册的菜单：

```powershell
Start-Process -FilePath "D:\应用\大屏媒体浏览器\media-browser.exe" -ArgumentList '--unregister-context-menu' -Wait
```

只写 HKCU，不改默认文件关联，不注册服务或开机启动。未来安装器应把注册作为用户级可选项，卸载在删除程序前调用清理命令。本轮尚无正式安装包，以上命令不等于安装器验收。

## 注册范围与引用处理

注册 `HKCU\Software\Classes` 下 `Directory\shell\MediaBrowser`、`Directory\Background\shell\MediaBrowser`、`Drive\shell\MediaBrowser`。普通目录及盘符使用 `%1`，背景使用 `%V`。命令为带引号的完整 exe 路径，以及 `--open "%1\."` 或 `--open "%V\."`。

末尾的 `\.` 用来避免磁盘根路径的末尾反斜杠吞掉 Windows 命令行的结束引号；它规范化后仍是原目录。未使用 cmd、PowerShell 表达式或 shell 脚本解释用户目录。

注册前检查所属标记，拒绝覆盖非本程序项；写入失败会尝试恢复已读取的注册值并报告回滚错误。卸载核对所属标记和规范化程序路径，旧安装不移除指向另一安装的入口。只移除三个本程序 verb，不删除 Directory/Drive 等共享父键，不改系统默认打开方式。

## 单实例与 IPC

普通启动先建立带当前用户 SID 的互斥体和本机命名管道，再创建索引工作线程和窗口；已有实例时转交目录并退出。诊断参数有独立作用域或显式绕开普通实例流程，测试时必须配合专属数据目录。

- 管道与互斥体采用显式保护 DACL，仅当前用户有允许项，管道拒绝远程客户端。
- 固定版本、最多 64KiB 的消息只表示打开目录或激活窗口；路径用 UTF-16 无损二进制传输，不解释任意命令。
- 客户端规范化目录，服务端再次验证绝对路径和目录类型；文件、非法帧、超长帧与队列满均拒绝。
- 待处理请求队列最多 8 项；连续请求保留最近的目标目录，激活请求不取消尚未处理的目录。
- 使用可取消的 overlapped I/O，空闲客户端不会卡住退出；不做无条件循环轮询。
- IPC 从 eframe `App::logic` 处理，即使窗口最小化、没有绘制回调也能接收请求，发出恢复和焦点请求后走同一个目录导航流程。
- 回收期间暂存目录请求，避免改变已经确认的删除目标；该组合仍需更完整的竞态验收。
- 窗口隐藏时继续处理回收结果与退出计时，并暂停视频；显示后恢复详情原来的暂停意图，列表仍需要重新满足悬停条件。

不同登录会话、UAC 完整性级别组合和更广的焦点策略尚未测试，不宣称跨环境全面兼容。

## 当前证据

`instance::tests` 三项测试核对固定协议、实际对象 DACL、同用户转交、8 项队列上限、文件拒绝、退出后重开和沉默客户端下的可取消退出。`shell_menu::tests` 两项测试核对引号/根路径参数及 HKCU 独立测试子树中的所属标记、升级、旧卸载保留新注册、非本程序项保留和清理。

`tools/run_system_integration_smoke.ps1` 把程序复制到含空格和中文的专属目录，注册带随机标识的当前用户测试 verb，通过实际 ShellExecute 分别调用目录和临时盘符根目录，并读取同一原生进程准备好的媒体根目录。临时盘符只映射到专属一图目录，不扫描整块真实磁盘。

脚本还检查背景注册命令的实际参数展开、激活不重复导航、文件目标拒绝、新旧安装所属检查、退出重开、菜单与盘符清理，以及四份测试图字节不变。背景检查通过直接进程启动执行实际注册命令，未冒充真实 Explorer 背景 IContextMenu 点击。

首次脚本报告误包含 PowerShell provider 元数据而递归展开，已停止该诊断进程、核对并清理其测试菜单/临时盘符，改为只序列化需要的注册字符串值。该中断执行不计通过。

Debug 窗口后端已记录实际最小化再恢复：约 1331ms 时为已最小化、约 1503ms 时恢复，六次转交均为同一进程。这是一次本机实例，不能推断所有机器恢复延迟。Release 构建与同构建回归完成后，以 `artifacts/p4-current-verification.json` 为最新证据。

## 本轮 Release 结果

当前预览程序 SHA256：`6817C29794148BC45DFE8AA70890C36D25CE4E2C378963AA3B8434A939175DE0`。56 项测试通过、3 项忽略；系统集成、回收站、扩展输入、播放接续、GIF、watcher、列表/详情七组原生回归在同一 Release 上通过，见 `artifacts/p4-current-verification.json`。系统集成明细见 `artifacts/p4-system-integration.json` 与 verifier。测试三个菜单键和临时盘符均核对移除，四份媒体副本哈希不变。
