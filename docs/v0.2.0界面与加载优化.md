# 掠影 Glimpse 0.2.0 本地测试版

2026-10-21。保留 Rust / egui / libmpv GPU 技术栈、原文件及既有功能。本文件仅记录本轮构建，旧版报告保留历史身份；完整首版与 Win11 验收没有宣告完成。

## 界面与使用

- 移除列表系统标题栏。左侧采用 Logo 与斜体「掠影 Glimpse」字标；拖动字标移动窗口、双击最大化/还原；操作栏右侧提供最小化、最大化/还原、关闭。目录输入框最大 420 逻辑像素，余下空间留给窗口操作。
- 常规密度改成旧紧凑密度；新的紧凑模式进一步收窄。媒体间隙常规 8、紧凑 4 逻辑像素，控件上下间隔常规 6、紧凑 3；目录行常规 40、紧凑 35。
- 缩略图滑杆改成倒数曲线并修正列数取整，避免大半段都只有两列；末端仍强制单列，原始图片比例保留。
- 请求可见卡片按屏幕从上到下、同高度从左到右排队；异步解码完成时间取决于文件大小与格式，不能承诺每行同时出现。
- 侧栏新增固定目录、最近访问、常用目录。打开目录后记录访问，右键固定/取消固定；当前目录也可直接固定。记录与配置仅本地保存，重启保留。去掉侧栏重复品牌区。
- 修复中文字体回退字重：完整字体默认可变轴是 100，现固定为 400，与界面子集一致；标题与正文的语义层次仍保留。
- 应用及安装器 PE 版本与 Cargo 版本统一。本次为 0.2.0；打包脚本拒绝复用不高于已有新式交付的版本，后续每个新包需先增加版本号。仅同一包的源码/文档刷新不增加二进制版本。

## 图片与视频加载

图片保留先读尺寸、柔化预览再替换清晰图。增加最多 128 MiB 的解码源图缓存，减少非 JPEG 在预览/清晰阶段重复解码；JPEG 保留缩小解码。GPU 缓存仍限 256 MiB，后台结果队列与任务数量有界，不加载整个文件夹原图到内存，也不压缩改写原片。

视频不再等待整个目录读完尺寸：未知尺寸先用临时 16:9 排布，可见封面优先、后续尺寸低优先级处理；真实画面按真实比例显示。两名视频工作线程，联网目录减少屏外预取。未知视频尺寸后续到达仍可能造成局部重排，这是优先显示首屏与严格尺寸排版之间的取舍。

增加有界 MP4/MOV/3GP 头读取路径。常规可识别轨道直接取尺寸；复杂旋转、非方像素、未知结构回退 FFprobe。对于本次发现的碎片 MP4，头部没有总时长，封面先读取可解码的首帧，总时长后台补齐；不把未知时长伪装成 0 秒。后台任务在前台需要资源时让出，播放引擎仍支持原有拖动/快进和声音。

### 真实局域网目录观察

用户授权只读测试路由器挂载盘。初次枚举 590 个视频；后续运行扫描出 592 个媒体，目录在变化，不能当冻结的完全一致数据集。操作系统和路由器缓存未清空，不能据此给出固定倍数或 SSD 带宽结论。

先前 0.1 构建运行 30 秒没有产出封面。优化构建 f13832a1 的新应用缓存测试：第一个封面文件 1.359 秒、8 个封面 2.406 秒；原生绘制回调首次就绪 1.103 秒、首屏 16 张全部就绪 3.365 秒。30 秒时 48 项尺寸已就绪、失败 0；后台仍继续读取其余媒体。该计时是管线/原生绘制回调观察，不是显示器实际呈现时间，也不是视频起播延迟。该构建之后仅作侧栏与受控测试命中修正，最终包仍需单独绑定证据。

原始路径、文件名、目录数据库和私人媒体截图留在本机 target/artifacts，不收入交付包。交付只附去标识数字摘要与公共测试图片截图。

## 验证与边界

库测试在普通桌面权限下 71 通过、1 项显式诊断夹具导出忽略；受限环境先出现 6 项权限相关失败，普通权限复验全部通过。没有放宽回收保护或测试断言。此前主程序测试为 17 通过、2 项忽略；去重测试已改成等待实际完成后验证重复请求不新增事件，避免固定 500ms 的机器速度假设。

实际原生截图检查了主列表、侧栏、菜单、详情、六类设置及 100%/200% 应用缩放；对重复品牌区进行了真实截图后的迭代。缩放截图属于应用渲染验证，不能替代 Windows DPI、多显示器或物理鼠标测试。输入诊断改为点击媒体可用区域，避开吸顶条及播放控件；检查目标仍包括有声预览、进度、快进、详情切换与多选菜单。

本轮最终二进制、格式矩阵、回归及包校验结果以本目录 verification 中的 JSON 为准。完整 A01–A24 历史清单仍见《A01-A24验收记录》，不能把旧构建证据等同于本次构建。Win11、干净系统、真实 iPhone 10-bit/HDR/杜比视界、物理输入与普通桌面单实例完整场景仍有未验项。应用开源许可证按用户要求暂不决定，当前为本地测试交付。

## 最终包复测补充
