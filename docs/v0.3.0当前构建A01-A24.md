## 当前证据入口

- `verification/index.json`：本轮与此前 0.3.0 功能交付证据索引及哈希。
- `v030-final-regressions.json`：设计、目录树、输入、播放四类原生回归，绑定生产源及应用哈希。
- `v030-presentation-final-verification.json` / `v030-presentation-final-raw.json`：2–5 张组合、双击、暂停、混合顺序/EOF、拖动请求与路径控件。
- `v030-format24.json`：本轮 24 格式的实际运行和逐项结果；各源文件 hash 运行前后核对。
- `v030-performance-summary.json` 与 startup/scroll/idle/scan 原始 JSON：打包 Release 测量、机器和样本身份；不能以内部回调替代物理呈现。
- `v030-final-package-verification.json` / `v030-source-build.json`：载荷/源码及运行时恢复检查；不是干净机器安装证明。
