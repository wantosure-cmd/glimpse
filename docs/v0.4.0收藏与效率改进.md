# v0.4.0 收藏与效率改进

本轮保留 Rust / egui / libmpv 技术栈。应用版本由 0.3.1 更新为 0.4.0。

## 使用

- 媒体右上角星标可收藏/取消；已收藏星标常显，未收藏在悬停时显示。详情右上角和右键菜单同样支持收藏。
- 顶部「收藏」筛选当前资料库；「仅选收藏」只选当前结果中的收藏。目录右键可选中该目录及其子目录内的收藏。
- Ctrl+C / Ctrl+X 把选中文件写入 Windows 文件剪贴板，资源管理器粘贴时复制/移动。剪切本身不立即移动源文件。原有复制路径命令仍保留。
- 目录右键「清理非收藏媒体和空文件夹」：先核对目录和数量，确认后有 10 秒撤回期。先回收非收藏媒体，再由深到浅检查空目录。字幕、文档、隐藏文件、收藏文件及有内容的目录保留；所选根目录保留。
- 回收站不可用沿用明确人工确认的永久删除流程；绝不自动降级。空目录请求在提交及 Shell 删除前复查；永久删除空目录使用非递归 remove_dir，出现新内容时拒绝。
- 视频音量滑块与设置统一支持 0–400%，libmpv volume-max 同步设为 400。放大可能使原音频削波，应按实际听感调整。
- 关闭热区延伸至窗口右上角；保持现有自绘标题栏拖动、最小化和最大化。
- 操作栏空白区域显示本进程 CPU、工作集内存、I/O 读取速率，悬停查看详细读写值。每秒采样，CPU 按逻辑核心归一化。进程 I/O 不等于硬盘物理吞吐，不包含外部解码子进程或显存；窗口宽度不足时隐藏性能栏以保留操作按钮。
- 设置 → 常规 → Language 可即时切换简体中文 / English，正常退出时保存。文件名、目录及操作系统/第三方错误保持原文。
- 从左上角选择框按住拖动，或先选中一个媒体再按住该媒体拖动，可沿鼠标轨迹连续选中；靠近列表上下边缘自动滚动。保留单击打开、Ctrl 多选和 Shift 范围选择。

## 本地数据与技术

收藏存于数据目录 favorites.json，以规范媒体路径为键，先写临时文件再替换。不写原始媒体；改名/移动后不自动跟随。损坏或不可读的收藏文件不会被空集合覆盖，并禁止依赖该集合的清理操作。

收藏筛选在现有后台布局准备请求中筛选快照，不逐帧重建瀑布流。清理的源候选来自完整扫描快照，独立于「只看收藏」过滤结果，提交时重新保护新增收藏，并复用现有指纹核对、文件释放和回收结果流程。

界面共有 555 个稳定词条 ID，中文和英文 catalog 同键、同格式化占位符，编译进应用；运行时只切换语言标记，无联网、动态 JSON 翻译或技术栈迁移。格式化词条由 ui_format! 保留 Rust 编译检查；回收失败分支匹配两种语言，避免切换语言影响安全判断。

真实窗口新增交互、原有设计/目录/播放/轮播回归及交付检查结果将在最终交付时列明。Win11、实际物理鼠标在显示器角落点击和资源管理器实际粘贴不据静态代码检查宣称通过。
