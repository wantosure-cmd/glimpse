# 0.4.11 快捷键与旋转诊断

本轮补齐原生编辑诊断的输入前提与可观察性。普通浏览界面、快捷键路由、后台输入拦截和旋转实现不改。

## 两种诊断模式

原有 `--edit-smoke <输出目录>` 继续使用框架报告的实际输入焦点。新增的 `--edit-smoke-controlled-focus` 只有与编辑诊断同时启用才生效；普通启动不会创建该诊断对象，也不会覆盖焦点。

验证脚本对应新增 `--controlled-focus`，默认不启用。报告逐次记录合成按键、原始焦点、施加的应用输入焦点和受控标记；不能把受控模式当作 Windows 真实前台或物理键盘证明。

受控模式不是一律放行：先在失焦状态发送 PageDown，要求不切图；再在前台状态要求下一张。PageUp 同样先验证后台不响应，再验证上一张。之后批量旋转仅生成的 JPEG、PNG，要求文件写回、格式保留、元数据更新、实际 GPU 像素方向正确、快捷键设置持久化。原件和标记文件必须不变。

## 已取得的原生结果

应用 SHA-256：`41964fb6df7343f7c797ac0258689bdf95524572f1b007fb72bce701c2dc4eed`。

- 24 项主程序测试通过，2 项原有忽略；556 项文案检查通过。
- 受控模式通过四组输入条件，后台前后切换均被拦截，前台前后切换正确；记录原始焦点与受控状态。
- 不覆盖焦点的默认模式也单独通过：两次合成 PageDown/PageUp 到达时，原始焦点和输入焦点都为 true，`controlled=false`。这是本次观察条件下的原生输入结果，不是物理按键或所有桌面会话的保证。
- 两种模式均实际写回 JPEG、PNG 且保留格式；旋转后 GPU 象限颜色平均差分别约 0.17、0.92（阈值仍为 15，没有放宽）。测试原件和标记不变，快捷键配置保存为 PageUp/PageDown。
- 实际查看旋转后的原生 FBO 截图，箭头与四象限顺时针旋转正确，详情缩略图同步更新。

0.4.10 的三次失败、只加日志的 Debug 副本结果及桌面捕获超时仍保留在原版本档案，不能由本轮通过反推其当时已通过。本轮没有修改正常输入路由以绕过失焦保护。

## 交付与范围

新应用包递增为 0.4.11。便携版、安装器、完整源码、依赖锁定、Lucide 原始 SVG 与许可证、构建说明和原始验证结果一起交付。安装、打包与后续实测以 verification 内对应 SHA 的结果为准；不会把旧版本的性能数字计入本版。

只修改专门生成的副本，不用真实资源库测试旋转或删除。Win11、干净离线 GPU 环境、物理输入/显示器呈现、系统 DPI 和真实 iPhone HDR/杜比视界原片等缺口保留；完整首版未全验收。


## 本版完整运行补验与性能

当前 24 格式、两张用户 HEIC 原片只读解码、86 项库测试、17 项收藏/涂选/400% 音量/语言/清理扩展，以及原生设计、导航、输入、目录通知检查通过。原生 Delete 共 6 批，包含锁定部分失败、按住去重及删除后切图；6 个副本按回收凭据全部恢复且哈希不变，3 个测试原件未变。未用真实图库执行旋转或删除。

当前本机实际安装/卸载、HEIC/MOV 探测、自身版本登记 0.4.11 与非空目录/联接点/运行中覆盖保护通过；独立作用域的两个进程准确转交、副本未变。源码与最终包字节分别独立核对，结果见 verification。便携/安装器内说明是打包时的诊断记录，新增运行与性能证据另附于外层 verification 和最终源码说明。

机器：Windows 10 Education 22H2 build 19045.6456、Ryzen 7 2700X、16 逻辑处理器、16GiB RAM、RTX 2070。样本是 5000 项生成图库，前后全部哈希一致，不是路由器上的 580 个视频。编译、其他 GUI 测试与性能测量分开运行。
