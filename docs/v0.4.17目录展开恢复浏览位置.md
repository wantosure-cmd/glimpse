# 0.4.17 目录展开恢复浏览位置

修复：浏览到目录中段后收起目录，再展开会回到目录开头。此前折叠和展开都会设置pending_folder_location，异步布局完成后强制定位标题，覆盖原来的媒体滚动锚点。

现在在收起前保存该目录范围内可见媒体的ID及屏幕偏移；重新展开时恢复媒体锚点，清除与之冲突的目录标题定位。每个目录分别记录，父目录也可以恢复到其后代媒体。第一次展开、原媒体已移除或被过滤时使用目录定位回退；进入另一个独立目录树时清空这些临时记录。记录只保留在当前会话，不新增持久化数据库或整库解码。

新增原生目录导航回归：在子目录媒体中段折叠/展开，以及折叠根目录后展开，两次恢复均核对媒体锚点误差不超过1逻辑像素。原有空白折叠、吸顶折叠、目录定位、祖先展开、图视频动效与单列最大缩略图检查继续运行。实际结果以本次0.4.17运行报告为准；此文件描述实现和测试要求，不用编译成功代替原生测试通过。

旧0.4.16的格式、安装与性能数据只保留为历史证据，不冒称本版重测。Win11、干净离线GPU环境和实体输入/系统DPI等完整首版缺口保留。
