# 掠影 Glimpse 0.4.2：视频列表稳定与滚轮速度

2026-10-22。保留 Rust / egui / GPU 视频引擎、界面风格和既有媒体操作，继承 0.4.1 缩略图性能优化。

## 修复内容

### 视频加载时列表不反复重排

此前，未知尺寸视频先分配临时 16:9 卡片；异步读到真实横屏、竖屏或方形尺寸后，重新计算瀑布流，可能让后面的卡片换列、改变整页高度。仅恢复纵向锚点无法阻止这种换列。

现在，后台排版复用当前已显示版本的**视频卡片尺寸**，以文件指纹校验，避免元数据分批返回时反复重排。真实宽高、时长和视频播放仍使用真实元数据，画面等比放入卡片，不拉伸、不裁切；首次尺寸未知的视频可能在卡片内留边。重新打开目录、主动缩放缩略图或改变窗口宽度时，按当时已知尺寸重新排版。文件被替换时不继承旧文件的卡片比例。

已知尺寸的视频仍按原比例初次排版；图片继续走原有的尺寸先行逻辑。收藏过滤、排序、目录折叠、定位和删除机制保留。稳定尺寸表只保存指纹与宽高，不额外缓存原图或视频帧；后台使用哈希表查找，避免逐项线性查找形成平方级开销。

### 列表滚轮提速 1.5 倍

仅媒体列表的纵向 ScrollArea 设置 1.5 倍滚轮系数，沿用 egui 原有平滑滚动。横向、目录侧栏、设置页和详情页缩略图列表不改速度；视频滚轮快进/快退由既有输入路由先消费，仍为原有步长。选择 1.5 倍作为默认值，避免直接加倍后容易越过当前浏览行。

## 验证方式

- 580 个视频模拟分十批返回横屏、竖屏、方形尺寸，检查所有卡片矩形、列表高度、滚动锚点完全一致；主动缩放、文件替换后检查真实比例生效。
- 使用生产列表滚动组件运行 egui 输入帧，对比普通滚动和新滚动的实际位移，覆盖 Line / Point 滚轮事件；检查位移为原来的 1.5 倍。
- 新增只读原生异步专项：580 个生成 H.264 视频，横屏、竖屏、方形混合；隔离应用缓存，观察真实后台读尺寸时的卡片几何摘要和顶部滚动位置，检查源哈希。
- 沿用原生界面、目录/动效、输入/视频播放回归，覆盖详情缩略图滚轮、侧键切换、列表视频快进和返回列表。

定向布局测试 **8 项通过**；主程序 **22 项通过、2 项忽略**。原生 580 视频测试在 40 秒观察期取得 50 份符合条件的记录，已读尺寸从 0 增至 32 时，卡片几何摘要始终只有 1 个值，顶部滚动位置保持 0，源哈希不变；首个预览约 853 ms。这证明本次已观测的异步更新没有造成重排，不是声称 580 个视频均已解码。分十批覆盖全部 580 项的情况另由布局回归验证。
