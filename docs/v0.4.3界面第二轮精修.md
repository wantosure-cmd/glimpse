# 掠影 Glimpse 0.4.3：Raycast 风格第二轮精修

2026-10-22。保留 Rust / egui 0.37、GPU 视频方案及原有业务流程。这一轮集中统一组件和视觉权重，没有改换技术栈，也没有增加渐变、发光或整窗玻璃效果。

## 改动与前版对比

| 范围 | 0.4.2 | 本版 |
| --- | --- | --- |
| 工具栏 | 筛选、收藏、排序和媒体操作连续排列，多个描边按钮 | 导航与内容控制分层；第二行按类型、收藏、排序、尺寸、选择分组，次要按钮去掉默认实体边框 |
| 媒体卡片 | 2px 强调边线、大色块勾选背景、固定宽度时长底牌 | 1px 选中边线，小勾选标记保留原热区，收藏仅小星形常驻，时长按文字宽度绘制 |
| 播放器 | 文字音量/全屏按钮、大字左右箭头，顶部信息较粗 | 共享线性图标与小浮层，整行进度，左右导航缩小视觉尺寸而保留热区，当前缩略图边线减细 |
| 滑块 | 大圆点与描边，视觉权重偏高 | 复用原 egui Slider 的输入、范围与点击尺寸，仅收小绘制尺寸、统一 Hover 和 Focus |
| 弹窗/通知 | 各处分别定义底色、边距和圆角 | Dialog、Popover、Toast、媒体 Loading 共用设计 Token 和组件；真实删除进度可见 |
| 状态信息 | 正常状态直接展示扫描耗时等技术文字 | 正常状态简化为“媒体库已就绪”，原始耗时等保留于悬停提示，错误和风险仍直接可见 |

共享实现见 `src/browser_components.rs`，完整值与交互约束见 [组件与状态规范](界面组件与状态规范.md)。新增一条中英文状态文案，两个语言目录共 556 个词条，继续静态编译进入原生程序。

## 实际视觉迭代

第一轮发布构建启动后，检查了列表、视频详情、菜单与 100% / 200% egui 缩放设置页的真实 GL 截图。发现滑块圆点仍偏大、外观预览边框较粗、部分浮层还保留独立配色，随后进行了第二次代码微调和构建。

最终构建再启动并运行原生回归；完整证据保留在交付目录 `verification/`。其中旧版截图与最终截图按页面归档，可通过 `visual-review.html` 对照。生成目录名、加载进度和视频播放时刻可能不同，不能把这些差异当作设计改善；比较重点是组件、层级、对齐、字级与状态表达。

最终主程序 SHA256：`91f8334dad0c7ab3820f808543e9e36853451f8b78df7edc6af254475fe71da6`。已检查最终列表/目录、菜单、播放器、中英文设置、多选和缩放截图；滑块点击范围保留，绘制圆点已缩小，详情文件信息、导航和控制栏使用同一组表面、图标与字级。
