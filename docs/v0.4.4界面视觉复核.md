# 掠影 Glimpse 0.4.4：第二轮界面交付复核

2026-10-22。保留 Rust / egui 0.37 原生界面及 libmpv GPU 视频，不重写技术栈。第二轮组件实现与两次视觉迭代见 [0.4.3 改造说明](v0.4.3界面第二轮精修.md)，本版保留这些改动，补齐当前构建的回归和截图复核。

## 逐项复核

| 项目 | 实现和截图检查 |
| --- | --- |
| 工具栏 | 第一行导航、路径、窗口操作；第二行类型、收藏、排序、尺寸、选择分组。次要按钮默认无描边，性能文字降为辅助层级。 |
| 媒体卡片 | 原始比例不变；1px 选中线、17px 勾选视觉保留 28px 热区；收藏小星形；时长标签随文字宽度，不遮挡整块内容。 |
| 播放器 | 顶部文件信息、左右导航和底部播放栏使用共享表面、字级及线性图标；时间位于进度两侧，音量及全屏为轻图标。 |
| 通知与弹窗 | 共享 Popover、Dialog、Toast、Loading；错误仍直接显示，删除显示真实进度。媒体占位静态绘制，避免大量持续动画。 |
| 状态规范 | 共享 Token 定义颜色、圆角、线宽和字级；Hover、Focus、Selected、Disabled 分别表达；缩小视觉元素不缩小原有热区。 |

实际检查了当前构建渲染的列表/侧栏、图片菜单、视频控制栏和 200% egui 缩放设置截图：菜单图标与文字对齐、次要文字层级、边框和圆角一致；播放器与主窗口共用组件。没有增加发光、渐变或整窗玻璃效果。交付 `verification/visual-review.html` 提供 0.4.2 与当前构建对照，测试目录名、视频时刻及媒体数量不同不作为视觉改进证据。
