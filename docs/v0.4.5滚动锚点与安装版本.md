# 掠影 Glimpse 0.4.5：滚动锚点与安装版本

2026-10-22。继续按原规格补验 Windows 首版；保留 Rust / egui、GPU 视频、第二轮视觉组件及全部媒体业务。完整首版尚未全验收。

## 修复

1. 安装器的 Windows 卸载登记 `DisplayVersion` 原先固定为 `0.1.0-local-test`，现取编译时 Cargo 版本。主程序、安装器 PE 版本和新交付版本继续一起递增。安装验收工具增加实际注册版本核对；未运行注册场景时不会把它记成已验证。
2. 外部变化刷新时，图片尺寸分批返回会暂时缩短内容高度，滚动区在恢复锚点后又按临时高度夹紧位置。现在仅当视图仍包含原有卡片、分组折叠状态相同且布局尺度相同时，在尺寸未完成期间保留已有滚动范围。真实删除、筛选、折叠及窗口缩放仍允许正常缩短；元数据完成后采用实际高度。不添加虚假媒体单元格、不提高像素缓存预算。
3. 外部变化测试原先用固定滚动量，可能恰在空隙或异步布局发布之前取不到锚点。现先确认实际卡片内部的非零滚动位置再开始变化测试；45 秒总期限、刷新后误差不超过 1 像素、选择保留及源文件保护要求不变。历次原始失败分别归档，不能把失败记录删掉后只保留通过。

布局新增回归覆盖：尺寸缺失时保留已有高度、真实删除不保留旧高度、窗口缩放重新计算，以及尺寸补全后回到实际高度。目录比较使用哈希索引，避免逐组平方级查找。

仅保留高度还没有完全解决子目录偏移，原生复验仍观察到约 59 像素漂移。逐帧记录显示卡片几何保持不变，滚动值仍持续衰减；根因是 egui 在测量本帧内容之前，用上一帧较小的边界积分回弹。现在程序显式恢复位置的那一帧暂时禁用该区域的越界回弹，绘制完成后立即恢复原设置；普通鼠标滚动仍为原来的 1.5 倍，并保留正常交互设置。新增真实 egui 回归先在对照路径重现漂移，再验证保护路径无漂移、样式恢复，不以放宽误差阈值解决失败。

最终优化主程序 SHA256：`e0daab4fb3b8e1e59537517dabcbeec9d8dcaae9c6a4222e8dddd52b2175de7d`。低优化诊断构建只用于定位，不能充当最终 Release 性能证据。

当前优化构建的外部变化专项通过：根目录新增、同路径替换、移除及手动刷新；进入子目录后，父目录/兄弟目录计数及刷新锚点检查通过，两个锚点误差均为 0。GIF 的循环/有限次数/单次播放、帧色、单纹理复用和时序通过，最大误差约 10.5ms。GIF 验证器另修正了源码构建运行时路径解析，并按锁定清单核对 FFmpeg；原始路径/清单定位失败日志保留。

Release 库测试 85 通过、1 忽略；主程序 23 通过、2 忽略；安装器载荷边界测试 1 通过。长路径原生扫描、图片/HEIC及MOV/AVI/3GP播放专项、损坏索引备份/恢复及未来版本拒绝、设计/目录/输入/播放专项通过。具体路径长度、格式样本和进程身份以同构建 JSON 为准。

## 当前交付 Release 性能

使用交付目录中的最终程序，5000 个生成重复媒体，3840×2160 / 150% egui 缩放，两轮各 120 秒：UI 回调间隔 P95 **18.05 / 18.22ms**，主进程峰值工作集 **254.41 / 186.09MiB**，纹理计费上限 256MiB，预览错误均为零；空闲采样 30 秒，总 CPU 归一化占比约 **0.013%**。两轮前后 5000 文件哈希一致，测量期间没有并行编译/打包或其他专项。生成重复样本、主进程工作集及回调间隔不能当作独立摄影图库、全部子进程资源或显示器呈现证明。

首轮 20 次启动保留长尾：外部 WaitForInputIdle 中位数/P95 **204.22 / 449.06ms**，内部首次 UI 回调 **282 / 976ms**。完整滚动/空闲结束后，同一程序另测 20 次，内部回调中位数/P95 为 **245.5 / 296ms**，外部 P95 约 **241.82ms**。后测没有替换首轮原始值，也没有改代码；间歇长尾原因尚未确立，不能把它归咎于系统或宣称已经修复。两个指标起点不同，不能相减；它们都不是规范中的“可见且可交互首帧”，启动时延目标继续未验证。

资源/回调等可观测门槛以 `v045-performance-summary.json` 的具名项为准；其 `full_acceptance_pass` 和启动目标验证均保持 false。首屏完成 P95、重启冷启动及物理 seek P95 未测，不因现有代理指标通过而降格替代。

本轮原始证据和最终构建身份以交付 `verification/index.json` 及各专项报告为准；每项只按实际结果记录，不把上一版成绩自动转给新版。0.4.4 的 314 文件源码 ZIP 已独立解包、恢复锁定运行时并通过 `cargo check --bins --locked --offline`，记录保留在该版交付；这利用了本机现有 Rust/Cargo/MSVC 环境，不是无工具链或无依赖缓存的离线编译。
