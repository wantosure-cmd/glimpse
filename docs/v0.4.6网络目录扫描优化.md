# 0.4.6 网络目录扫描优化

2026-10-22。本版将目录扫描中的逐文件 `fs::symlink_metadata(path)` 改为 `DirEntry::metadata()`。后者在Windows复用枚举返回的属性，不额外逐文件发起系统查询，也不跟随符号链接；仍保留原有reparse-point检查、取消/背压/错误反馈。解码和删除路径中的当前指纹检查没有取消。依据：[Rust官方接口说明](https://doc.rust-lang.org/std/fs/struct.DirEntry.html#method.metadata)。Unix行为仍相当于symlink_metadata，未自行引入平台重写。

## 修改前证据

真实只读目录：`\\192.168.31.1\XiaoMi-NVMe(b520)\XiaomiCamera_00_E0A25A2763A2`。这是持续变化的摄像机目录，不是冻结样本。0.4.5首轮45秒测试识别642媒体，首预览907.85ms、16张可见卡片全部就绪6916.55ms；应用独立空缓存，OS/路由器缓存未冲刷。详见上一版补验报告。

`tools/probe_scan_metadata.rs` 独立只读对照，顺序为逐项查询/枚举属性/枚举属性/逐项查询/枚举属性/逐项查询。644条目每轮文件名、大小、修改时间、Windows属性完全相同。逐项查询5527.34/4521.34/4476.61ms，中位4521.34ms；枚举属性102.23/83.56/102.34ms，中位102.23ms，约44.2倍。它证明枚举属性阶段收益，不能直接推断整屏44倍。原始记录：`artifacts/v045-network-metadata-comparison.jsonl`。

`tools/profile_network_posters.py` 使用正式0.4.5头部探测和同生产参数的分片MP4封面提取，只读8个按文件名排序的视频，不转换整库。8项均为3200×1800、分片且moov无时长；头部内部读取中位22.23ms，FFmpeg单帧进程中位209.90ms。源文件前后大小/修改时间相同，非全内容哈希证明。原始结果及生成封面：`artifacts/v045-network-poster-stages/`。该顺序阶段测量不是GUI端到端或起播测量。
