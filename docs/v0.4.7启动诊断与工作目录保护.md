# 0.4.7 启动诊断与工作目录保护

2026-10-22。最终主程序SHA256：`e1bc14449e60ce926d5e10e97fe4023961759fee1ef520a66fa2225fb8757ddd`。本版保留Rust/egui、GPU播放及既有媒体行为，完整首版仍未全验收。

## 明确修复

旧版普通启动也会在当前工作目录创建 `artifacts/browser-first-ui.json`，且在首帧前同步创建目录/写文件。工作目录可能是媒体目录或只读目录，这些开发诊断输出不应由普通启动产生。

本版默认不产生该报告；显式传入 `--first-ui-report <path>` 时仅在首次UI回调捕获数值，在正常退出时保存到指定位置。默认关闭的 `--startup-trace <path>` 增加main入口、实例初始化、原生窗口/渲染器、应用构造、UI和首个GL绘制回调时间点，亦在事件循环退出后写文件。未开启阶段诊断时不分配事件列表、不锁定记录器、不添加诊断绘制回调。既有启动测量工具已显式指定报告位置。

首次UI报告现在不包含旧版先创建调试目录的耗时；它始终不是物理可见或可交互时间。GL回调也不是swap、显示器呈现或输入响应的证明。DLL加载至main之前的耗时不在内部trace中。

## 实际回归

`tools/verify_startup_reports.py` 使用全新标记夹具和复制的PNG/哨兵文件。旧0.4.6负对照确实复现工作目录新增调试文件；新版普通空窗口、打开当前媒体目录、显式启用两个诊断报告三种场景，工作目录全部条目和原字节不变。显式报告在工作目录之外生成，trace PID/阶段、GL回调、退出及时间点匹配通过。没有修改用户图库或设置，也未注入系统鼠标/键盘事件。

当前主程序单元测试23通过、2忽略。首次debug测试中两个既有无GPU滚动测试丢弃了未处理TexturesDelta，触发epaint的debug析构断言；已显式清理这些无GPU测试的纹理输出，原1.5倍滚轮、对照须复现漂移、修复后误差小于0.1及样式恢复断言全部保留并通过。失败日志 `v047-main-tests-texture-failure.log` 留档，未禁用debug断言或改运行模式掩盖失败。

原生设计/GL回归和普通桌面独立实例转交结果以同哈希 `v047-current-design-verification.json`、`v047-current-isolated-instance.json` 为准。两个隔离进程的生成目录A→B转交，无用户实例接触或注册表修改。0.4.6也已按用户重新授权补验通过并追加到其verification；不把隔离转交扩大为物理Explorer菜单/主作用域/Win11证明。
