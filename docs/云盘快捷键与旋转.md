## 使用

- “打开文件夹”或地址栏可直接打开 `U:\其他\syl小米手机`。无需接入 115 账号/API；CloudDrive2 负责鉴权、联网和同步，本程序通过挂载路径读文件。云盘未缓存内容需要 CloudDrive2 联网，不能把挂载盘浏览称为完全断网可用。
- 工具栏“设置”可调整详情页上一张/下一张快捷键，默认下一张为**小键盘 0**、上一张为**小键盘 1**。需要开启 Num Lock，仅应用处于前台详情页时生效；顶部数字行不替代小键盘。输入文字、打开菜单或保存操作期间不切换。未被重新绑定的左右方向键继续默认切换。设置正常退出后写入应用数据目录 settings.json，不注册系统全局热键。
- 左上勾选照片后，点击工具栏“旋转照片”顺时针旋转 90°，或右键选择顺/逆时针旋转。右键所选照片时对选中的照片批量执行；右键未选中的照片时只旋转该照片。混选视频不会修改视频。详情页也有“旋转 90° 保存”。每次操作自动写回原路径，不需要另按保存。

## 保存规则

用户已确认“写回原文件、保留格式”。本轮采用无损方向标签编辑：JPEG 修改/新增 EXIF Orientation，PNG 修改/新增 eXIf，静态 WebP 修改/新增 EXIF 并维护 VP8X/RIFF，单页 TIFF 更新首个 IFD 的 Orientation。以原显示方向为基础组合 90°，包含已有镜像方向，不重复压缩图像，不把 HEIC 转成 JPEG。PNG/WebP 的压缩图像段、其他元数据及 TIFF 像素数据保留。

HEIC/HEIF、GIF、BMP、动画 PNG/WebP、多页 TIFF、BigTIFF 暂不能可靠写回，明确显示失败并保留原件。单文件无损编辑输入上限 256MiB。无效方向字段、重复 EXIF/损坏 PNG 校验、不确定格式、外部修改、只读或无法安全替换时报告错误。

写入在后台串行执行，先阻止所选文件的新封面任务并等待既有任务关闭，再写同目录专属临时文件、flush/sync、核对版本，用 Windows ReplaceFileW 安全替换并生成短暂恢复备份，核对备份确为读取的原内容后才清理。临界时刻的并发修改或替换失败会保留恢复备份并显示路径；不使用截断原文件或先删除再重命名的降级方案。保存期间普通关闭窗口会被取消，等待操作完成；不保证强制结束进程/断电时自动清理临时文件。

成功后清理该照片所有旧封面变体，清空 GPU 旧纹理，保留浏览位置并重新扫描/生成封面，避免云盘修改时间精度较低时仍显示旧方向。保存结果逐项反馈，不将批量部分失败当作全部成功。云盘是否支持 ReplaceFileW、最终上传及多端同步由挂载驱动决定；本轮没有对真实云盘文件做写入测试。

## 挂载盘兼容处理

旧版实际复现 `ERROR_UNRECOGNIZED_VOLUME (1005)`：目录可枚举，但 Windows 最终路径解析失败。读取路径现在优先 canonicalize，仅当 Windows 返回 1/50/1005 且普通路径元数据可读时使用规范化绝对路径。扫描、索引、单实例目录转交和播放器均采用同一读取处理。回收站的严格路径与回收能力检查不变，绝不降级为永久删除。

识别此类路径后，列表只为可见范围请求封面，不预读上下各一屏；封面进程和播放器加载等待从本地 12 秒延长到 60 秒。缩略图和索引仍存本地应用数据目录，不写媒体目录，不主动下载/转码整库。文件内容读取可能触发 CloudDrive2 自身的缓存下载。目录通知取决于挂载驱动，云端其他客户端改动未通知时可手动刷新或重新激活窗口核对。

封面 metadata 尚未返回时，视频详情使用播放器当前已解码的显示尺寸/方向计算实际画面和空白点击区域，避免竖屏画面的黑边误判为视频。相关属性依据 [mpv 0.41 官方属性定义](https://github.com/mpv-player/mpv/blob/v0.41.0/DOCS/man/input.rst)：dwidth/dheight 是宽高比修正后的输出尺寸，video-out-params/rotate 是显示旋转。
