# 交付构建格式与性能复验

更新：2026-10-19。应用 Release SHA256：`94EECB9EF6329F87E6F62725CA4A7A3102989E6A27559D1E656947D207D1EA15`。
安装器与便携 ZIP 沿用 `dist/0.1.0-local-test-20261019-cloud` 已验证的二进制；本轮不修改 Rust 程序，仅补充复验工具、报告和源码归档。整体目标仍未全部验收完成。

## 同构建格式实测

24 个基础格式用例全部通过：10 个图像和 14 个视频，覆盖 JPEG/PNG/WebP/BMP/TIFF、普通与合成 10-bit HEIC/HEIF、H.264/HEVC MOV/MP4、AVI、3GP/3G2、MKV、WebM。另两张用户 HEIC 均通过只读原生封面、详情与原像素方向映射复验。原始结果：

- `artifacts/release94-format-matrix.json`：24 个病例，每行保留实际运行证据目录。
- `artifacts/release94-user-heic-ui.json` 与 `artifacts/release94-user-heic-verification.json`：两张用户样本。
- `artifacts-release94-format-matrix.log`、`artifacts-release94-user-heic-ui.log`、`artifacts-release94-user-heic-verification.log`：原始执行输出。

检查覆盖真实原生封面/详情 FBO、已知样本尺寸/方向/像素、视频时间前进、WASAPI 会话信号、暂停后快进与新画面、浏览后源哈希不变。专用生成视频是实际合法容器和编码文件，不是旧手机实拍；两张用户 HEIC 主图均 8-bit。真实 iPhone 10-bit/HDR/杜比视界 MOV、完整 SDR 色调映射和专业颜色仍未验证。程序化输入和音频信号不是物理键鼠或主观听音验收。

## 机器与样本

本机 Windows 10 Education 22H2 build 19045.6456，Ryzen 7 2700X（8核16线程）、约16GB内存、RTX2070，D: 为 NTFS/aigo P7000Z NVMe。机器及卷的独立证据为 `release94-machine-verified.json`、`release94-fixture-storage.json`。初次受限环境 CIM 失败保留在 `release94-machine.json`，不引用其空字段作为机器事实。

5,000 个合法媒体来自专属重复样本集：4,590 JPEG、300 PNG、100 HEIC、10 MP4，100 个子目录；不是 5,000 张不同的高像素摄影原片。测试前后逐文件匹配生成源，最终清单 `artifacts/p2-perf-fixture-verification.json` 的 5,000 项全部相同。没有用真实私人资源库做性能写入、旋转或删除测试。

## Release 性能结果

| 测量 | 实际条件 | 结果 |
|---|---|---|
| 启动20次 | 每次新设置目录、空窗口，OS文件缓存已热 | 首次 UI 回调中位256ms/P95 444ms；WaitForInputIdle 中位218.07ms/P95 412.99ms |
| 冷应用缓存滚动 | 新空数据目录 `target/perf-ui-release94-cold4k-20261019`，4K/150%，120.01秒 | 回调P95 17.94ms/P99 19.08ms；工作集峰值 199.36MiB |
| 部分暖应用缓存滚动 | `target/perf-ui-release94-20261019`，4K/150%，120.01秒；此前800×600轮仅生成部分缓存 | 回调P95 17.97ms/P99 19.12ms；工作集峰值 137.57MiB |
| 空闲 | 首屏已缓存、预热15秒后采样30.13秒，无视频/持续诊断重绘 | 工作集约86.04–86.06MiB；采样CPU时间增量0，不能理解为任何环境绝对零开销 |

两个有效滚动轮的每个记录视口均为3840×2160，scale1.5，纹理账面峰值约256MiB，预览失败均为0。冷轮初始无应用缓存，但滚动重访会命中本轮生成的缓存（最终3,079次命中）；部分暖轮3,466次命中，不能称整库预缓存。两轮使用不同数据目录，不是严格的同一缓存配对实验。

此前 `release94-cold` 轮实际全程800×600，P95 18.18ms、工作集108.19MiB，因视口不符已排除4K成绩，原始记录未删除。补测用新标签 `release94-cold4k`，没有覆盖不符合条件的结果。

原始滚动证据为 `artifacts/p2-scroll-release94-{cold,cold4k,warm}.json`、对应 `-process.json` 和 `-summary.json`；启动与空闲为 `artifacts/release94-startup.json`、`artifacts/release94-idle.json`。汇总一致性入口为 `artifacts/release94-recheck-summary.json`。

UI回调间隔不等于显示器呈现帧率，进程工作集不包含全部GPU显存。首次UI回调与InputIdle不证明可见首帧并响应输入，不能据此将热启动可交互验收标为完成。冷应用缓存也不是重启后的系统冷启动。首屏可用P95、物理输入到seek目标画面的P95、大摄影图库仍需专项验证；10,000生成重复媒体的后续压力补测见《一万文件压力验证.md》。
