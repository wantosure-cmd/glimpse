# 单行播放栏与离线字幕

日期：2026-10-19。沿用 Rust / egui / libmpv GPU 渲染。

## 使用方式

详情页视频下方只有一行：时间、可拖动进度条、静音、音量和全屏。移除常驻播放/暂停按钮，空格或单击视频画面控制播放/暂停；进度条、音量、侧边切换按钮和右键菜单不触发画面暂停。视频比例外的空白仍返回列表。图片和列表页既有交互保留。

自动字幕：将 `旅行.srt` 与 `旅行.mp4` 放在同一文件夹，打开视频时由播放器加载。中文建议使用 UTF-8 编码，支持 UTF-8 BOM。云盘挂载目录仍交给播放器异步读取，不在 UI 线程扫描/读取字幕内容。字幕加载不改写视频或字幕文件。

手动字幕：详情顶部「设置 → 字幕 → 加载字幕文件…」，支持选择 SRT、ASS、SSA、VTT。原生选择窗口在工作线程打开；选择期间若切换了视频，丢弃旧目标结果并提示重新选择。手动选中的文件立即切换为当前字幕，加载失败显示错误并保留视频播放。

「设置 → 字幕」可显示/隐藏字幕、调整字号、垂直位置、文字颜色、黑色描边和半透明底框。位置从 0（上方）到 100（下方），默认 94；字号是播放器按画布缩放的相对单位，默认 36，可调 16–80。调整即时应用，正常退出保存，下次启动恢复。图片/视频中烧录的字幕和图形字幕不能当作可改文字样式的字幕。

三套预设：

| 预设 | 文字 | 背景与轮廓 |
| --- | --- | --- |
| 经典白字 | 白色 | 黑色描边和轻阴影，默认 |
| 暖金影院 | 柔和暖金 | 黑色描边和轻阴影 |
| 柔和底框 | 白色 | 半透明黑底，减少复杂画面的干扰 |

样式设置主要面向 SRT 等文本字幕，ASS 使用播放器的覆盖样式能力；不承诺覆盖每个 ASS 内联特效。自动匹配与参数语义参考 [mpv 官方手册](https://mpv.io/manual/stable/)。字幕由原 GPU 播放器合成，没有叠加第二套 CPU 视频解码。
