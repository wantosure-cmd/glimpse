## 启动：20次

使用 Windows PowerShell 执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/measure_local_startup.ps1 -Runs 20 -Output artifacts/glimpse-startup20.json -ExecutablePath dist/0.1.0-local-test-20261021-glimpse/media-browser-portable/media-browser.exe
```

每次使用独立配置目录、工作目录和实例范围，空媒体库启动，正常自动退出。20次均到达输入空闲、退出码0、加载便携目录中的CRT，并生成新鲜的首次UI回调记录。没有同时运行本轮编译、打包、滚动或媒体回归。

| 指标 | 中位数 | P95 |
|---|---|---|
| 外部 WaitForInputIdle | 192.63ms | 253.62ms |
| 内部首次 UI 回调 | 252.50ms | 273.00ms |

脚本对偶数个样本的中位数现取两个中间值的平均数，P95使用最近秩；原始20行的中位数与P95另外用Python独立核对。以前10次报告没有重写或合并。

**这些是温热OS文件缓存下的代理指标，不是实际显示首帧并可响应物理输入的时间。** 不能用低于500ms的代理值宣称规格的“热启动可交互P95≤500ms”已经完成；重启系统后的3次冷启动、实际首屏媒体呈现与物理输入响应仍缺。

## 空闲：当前构建

使用已有5000项专属生成媒体和本构建已填充的测试缓存，在正常浏览界面预热15秒后采样30秒。源文件在前后逐一对照生成清单；不操作用户图库，不使用持续重绘的诊断滚动模式。结果以 `glimpse-browser-idle.json`、逐项源hash及本轮机器记录为准。

实际采样30.5229秒，进程CPU累计0.015625秒，平均占总CPU约0.003199%，低于规格1%目标；采样工作集峰值142.98MiB，进程正常退出。前后5000文件逐项hash一致。该空闲采样没有同时编译、打包或运行本轮其他性能测试。

测量定义是该进程CPU时间增量除以实际采样秒数和16个逻辑处理器，工作集另记；不能把进程工作集当作GPU总显存，也不将该进程的低CPU解释为整个系统处于空闲。当前机器不是规格中集显参考机，Win11和不同机器仍缺。

机器补采确认为Windows 10 Education 22H2 build19045.6456、Ryzen7 2700X/16逻辑线程；注册显示适配器包括RTX2070，单独WGL能力探针返回NVIDIA560.94/OpenGL4.6，不将该隐藏探针当作应用FBO的设备证明。机器信息脚本首轮在Windows PowerShell5.1中因`[ulong]`类型别名不存在而失败；将PowerShell变量类型改为`[uint64]`后重跑成功，不更改C#声明或产品程序，失败没有当作有效硬件报告。
