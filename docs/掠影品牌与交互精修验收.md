# 掠影 Glimpse：品牌与交互精修

日期：2026-10-21。应用 SHA256：`e1e12d8a4c86b314b0c120a20bad52e309e135710964e1324986def208e48364`。新交付目录：`dist/0.1.0-local-test-20261021-glimpse`。这是原生 Rust/egui/libmpv 架构上的增量更新，旧 Raycast 测试包和用户设置/索引/媒体均保留，完整首版仍有后文列出的验收缺口。

## 本次改动

- 正式命名为“掠影 Glimpse”。窗口、设置、侧栏、空库界面、安装器文案与资源管理器菜单统一品牌。可执行文件名、存储目录、实例协议和注册表内部键保持兼容。
- Logo 用两张掠过视野的光页表达照片、视频与快速翻阅。应用内为矢量绘制；附 SVG、PNG，以及 16/24/32/48/64/128/256px 的 Windows ICO。EXE 与安装器嵌入图标和 Glimpse 产品版本信息。品牌素材说明见 `assets/brand/README.md`。
- 右键菜单统一为图标、操作名与右侧快捷键；30px 逻辑行高、轻量 Hover/Focus，删除操作单独警示，文件体积/尺寸收为小字底栏。列表、详情和目录的基本操作均保留。
- 修复重复打开详情后，复用的菜单可能落在详情层下面、看不到且点不到的问题；不是用静态图片遮盖视频。菜单在原生 GPU 视频上方真实渲染并可点击。
- 详情左上角改为紧凑半透明圆角浮层：返回箭头、左对齐的截断文件名、独立项数和弱化目录行；完整名称/路径可悬停查看，保留标题拖动、右键与空白返回。
- 侧栏使用品牌标记、图钉按钮、整行选中背景、线性折叠箭头和细层级线。目录名与计数分为两行，长名称截断；图片/视频统计包含后代，目录数只计直属目录，悬停可查本层及后代统计，单击仍是滚动定位。
- 系统集成读取失败的错误现在保留在对应设置页，不再覆盖主窗口的浏览状态。

## 视频左转与右转

列表视频和详情视频的右键菜单均提供左转/右转 90°。这是**播放画面旋转**：不修改、重封装或转码原视频；角度在本次运行内按文件版本记住，重启恢复原方向。图片的“旋转并保存”原功能继续写回原文件，未被视频旋转替换。

通过 libmpv 的 `video-rotate` 设置，在文件自带方向元数据之上增加用户旋转；每次加载文件均显式设置本文件角度，避免影响下一段视频。按用户角度交换已知显示宽高，列表播放器在原卡片内保持比例，详情适应可用画布。参考 [mpv 官方 video-rotate 说明](https://mpv.io/manual/stable/#options-video-rotate)。

## 同构建性能与交付

本机 Windows 10 Education 22H2 build 19045.6456、Ryzen 7 2700X、16 逻辑线程；机器和注册显示适配器信息见 `glimpse-final-performance-machine.json`。5000 项专属生成媒体，在 3840×2160、150% 缩放下连续滚动 120 秒，采集 7196 次 UI 回调：间隔 P50 16.66ms、P95 17.90ms、P99 18.62ms；进程工作集峰值 208.27MiB、纹理账面峰值 256.00MiB、预览失败 0。滚动前后 5000 个文件均匹配生成源 hash。证据为 `p2-scroll-glimpse-final-summary.json`、对应 raw/process、`glimpse-perf-fixture-before/after.json`。工作集不是 GPU 总显存，回调间隔也不是显示呈现帧率；本轮没有测物理输入至呈现延迟。

10 次使用独立配置目录的空库启动，输入空闲中位数 189.06ms、P95 230.39ms；内部首次 UI 回调中位数 247ms、P95 268ms，均正常退出并加载包内 CRT。证据 `glimpse-final-startup.json`。测量使用温热 OS 文件缓存，不是系统重启后的冷启动或首张媒体呈现。性能测量期间未并行编译、打包或运行本轮其他媒体回归。

交付使用 `tools/package_local.py` 校验固定 runtime 和第三方许可证文本；`tools/verify_raycast_delivery.py --tag 0.1.0-local-test-20261021-glimpse --prefix glimpse-final` 校验便携 ZIP、源码逐文件 hash、安装器内嵌 payload，并核对生产源码与实际测试构建一致。源码包含 `build.rs`、图标资源、锁定依赖、构建说明及品牌母版。`tools/verify_source_archive.py` 在新目录解压源码，恢复固定 runtime，使用本机已有 Rust/Cargo/MSVC 依赖执行 locked/offline 的全二进制编译检查；不宣称源码包自带全部开发依赖。
