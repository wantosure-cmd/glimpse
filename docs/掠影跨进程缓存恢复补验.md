# 掠影跨进程缓存恢复补验

日期：2026-10-21。当前交付应用 SHA256 为 `e1e12d8a4c86b314b0c120a20bad52e309e135710964e1324986def208e48364`。本轮仅新增测试工具和报告，生产代码、便携 ZIP 和安装器保持不变；执行前逐文件核对生产源码与交付记录一致。

## 实测方法

执行 `python -X utf8 tools/run_cache_recovery.py`。该脚本从已知格式矩阵复制公共/生成 PNG 和 H.264/AAC MOV 至全新 `target/cache-recovery-*` 专属目录，每次使用当前交付 Release 程序新建进程，同一病例复用独立数据目录。它使用程序原生诊断入口生成实际列表、详情、原尺寸/视频定位和返回列表画面，不发送桌面鼠标或键盘事件。

每个病例依次执行五次：首次生成缓存、暖缓存重开、将缓存 PNG 改为损坏字节、将缓存 JSON 截断为无法解析的内容、移除缓存 PNG。破坏操作只针对专属数据目录的生成缓存，不涉及用户缓存、索引、设置或源媒体。每次均等待前一实例正常退出。

恢复要求不只判断退出码：列表与返回列表须有真实纹理，记录尺寸须与已知样本一致，所有诊断阶段不得出现解码失败；实际列表/详情截图须有非黑画面，恢复列表的121个RGB采样点须匹配基线；每一个生成缓存 PNG/JSON 的文件名和内容 SHA256 必须与基线完全一致，且不得留下 `.tmp` 半文件；原始及复制媒体 hash 均须不变。
