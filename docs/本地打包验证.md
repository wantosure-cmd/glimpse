## 安装器设计及本机实测

安装器以现有 Rust 工具链编译，不依赖 NSIS。安装器静态链接 MSVC CRT；主程序的直接导入 `vcruntime140.dll` 放在 exe 同目录，原生图片库其他 CRT 仍旁带在 runtime 中。打包时核对 PE 导入及所有固定运行库哈希；不据此替代干净系统实测。

默认用户目录安装，只修改当前用户卸载登记；资源管理器菜单可选。拒绝非空目录、目录联接和已有运行实例。每个载荷按 SHA256 校验；支持从随包清单清理中断安装留下的已完成文件。卸载不递归删除整个安装目录，只处理清单中内容仍匹配的文件，保留未知文件和已修改文件。

最终安装器已在新建工作区专属目录实际安装：408 文件逐个 SHA256/大小校验、HEIC 解码和 MOV 元数据读取、正常窗口运行、运行期间安装/卸载拒绝、真实目录联接拒绝、非空目录拒绝、当前用户卸载登记及移除，全部通过；设置、未知文件、修改后的说明文件和媒体原件保持。记录 `artifacts/p5-installation-smoke.json`，其 installer_sha256 与上方最终文件一致。测试未修改真实媒体库或当前资源管理器菜单；安装器调用的菜单模块另有七组回归中的系统集成证据，不能混称此次安装器已物理点选菜单验证。

卸载从用户临时目录启动复制的工作程序，等待原卸载程序退出后移除安装文件。工作程序自身会留在用户临时目录，交由系统临时文件清理。当前版本不做覆盖升级；需先卸载旧版。没有强杀进程、管理员安装、服务、自动更新或永久媒体删除后备。

## 本机构建性能

机器：Windows 10 Education 22H2 build 19045.6456，Ryzen 7 2700X / 16 逻辑处理器，RTX 2070（驱动 32.0.15.6094），约 16GB RAM，aigo NVMe SSD P7000Z 2TB。此次只读查询记录在 `artifacts/p5-machine.json`。

5,000 个真实格式的专属重复样本：4,590 JPEG、300 PNG、100 HEIC、10 MP4，分 100 个目录。不是 5,000 份独立相机照片；前后逐个 SHA256 与生成源比对一致。每轮先等完整布局并预热首屏 10 秒，然后连续程序化滚动 120 秒；3840×2160 实际帧缓冲、150% DPI。两轮使用同一新 Release。

| 场景 | UI 回调 P50 / P95 / P99 | 进程工作集采样峰值 | 预览失败 |
|---|---|---|---|
| 空应用缓存 | 16.64 / 18.00 / 19.37ms | 196.47MiB | 0 |
| 已有应用缓存 | 16.66 / 17.75 / 18.64ms | 151.52MiB | 0 |

“空缓存”是新建应用数据目录，不是清空 Windows 文件缓存或重启后的物理冷读。UI 回调间隔不是显示器呈现时间，也不是物理滚轮延迟。工作集是进程 CPU 内存采样，不包含完整 GPU 驱动显存开销；纹理逻辑预算峰值约 256MiB，不能直接与工作集相加认定完整内存。此次测量未刻意隔离所有系统后台任务。

原始记录：`artifacts/p2-scroll-p5-cold.json` / `-process.json`、`p2-scroll-p5-warm.json` / `-process.json`，摘要各自 `-summary.json`，样本校验 `p2-perf-fixture-verification.json`。

20 次空窗口启动，每次新设置目录、Windows 文件缓存未清空：外部 WaitForInputIdle 中位数 181.68ms / P95 219.35ms，内部首次 UI 回调中位数 239ms / P95 276ms。每次实际进程模块都确认从 exe 同目录加载包内 vcruntime140.dll。原始记录 `artifacts/p5-startup.json`，脚本 `tools/measure_local_startup.ps1`。WaitForInputIdle 可能早于首次绘制，不能解释为首屏已显示；内部回调也不是显示器呈现时刻、目录扫描完成或首张媒体显示时间。

当前版本在 5,000 媒体首屏缓存已建立、无视频播放时，预热 15 秒后观察 30.26 秒，59 次进程采样，累计 CPU 时间增量在计时精度内为 0.0 秒。记录 `artifacts/p5-browser-idle.json`；不推断为所有浏览/解码场景 CPU 都为零。外层命令曾因未设置的 `$LASTEXITCODE` 被错误判失败；已直接复核进程 exit_code=0、采样数、时间与 CPU 差值一致，原始数据有效，未将该包装命令的异常当作产品故障。旧 P0/P2 构建数字不当作新构建成绩。

源码 ZIP 使用 `tools/verify_source_archive.py` 新解压到专属目录，经便携 ZIP 总 SHA256 和逐文件清单恢复固定 runtime，再执行 `cargo check --bins --locked --offline`。结果以 `artifacts/p5-source-build.json` 为准，明确依赖本机已有 Rust/MSVC/Cargo 缓存，不等同无开发依赖的断网编译。
