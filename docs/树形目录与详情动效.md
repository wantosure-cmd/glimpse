- 列表和侧栏显示目录层级缩进与细竖线；列表单元格随目录层级缩进，竖线贯穿后代区域。侧栏计数避开结构线。
- 普通点击目录名称只滚动定位，不切换根目录或重新扫描。定位折叠的后代会先展开祖先，再依据新布局定位。显式右键打开目录保持可用。
- 吸顶合并路径每一级有独立折叠按钮；名称仍用于定位。折叠会隐藏该目录的媒体和后代，展开恢复；多选、右键、回收与10秒撤回保留。
- 尺寸从图片头/HEIF容器、或视频ffprobe元数据提前获取，包含旋转方向；尺寸结果通过有界通道回写。列表采用尺寸布局后才显示预览/清晰像素，不在UI线程读文件，也不预解码整库。失败和切目录沿用generation/指纹校验。
- 图片详情的鼠标前进键下一张、后退键上一张，画面外空白同样支持；实际控件/菜单保留优先级。视频画面侧键仍为±5秒，视频外空白仍不触发目录导航。
- 详情缩略图区域滚轮向下下一项、向上上一项。支持一帧多项和精细滚动累计，到首尾停止；不会同时缩放图片或快进视频。切换后当前缩略图继续居中。
- 列表进入详情约200毫秒放大，返回约180毫秒收起。复用已有纹理/播放器GPU画面；冷播放器未就绪时可用已加载封面。计时从第一个绘制帧开始，避免初始化耗时吞掉动效。详情内部切换项目不重复入场动画。
