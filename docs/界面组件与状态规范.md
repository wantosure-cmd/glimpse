# 掠影 Glimpse：界面组件与状态规范

第二轮精修，2026-10-22。技术栈为 Rust / egui 0.37 原生绘制，保留 GPU 媒体引擎。共享组件入口 `src/browser_components.rs`，全局主题配置 `src/browser_ui.rs`，线性图标 `src/browser_icons.rs`。页面通过共享组件引用设计值，不各自建立一套主题。

## 基础 Token

| 用途 | 规范 |
| --- | --- |
| 画布 / 卡片 / 浮起表面 | `CANVAS` #131417 / `SURFACE` #1A1B1F / `RAISED` #202126 |
| 边线 / 主文字 / 次文字 | `BORDER` #313239 / `TEXT` #E1E2E9 / `MUTED` #91939E |
| 强调 / 危险 | 用户选定强调色，默认 #B1A0E7；`DANGER` #E88B92 |
| 媒体上浮层 | `OVERLAY`，小面积深色透明底，不使用模糊、渐变或发光 |
| 圆角 | 控件 6 / 卡片 8 / 菜单 10 / Dialog 12 逻辑像素 |
| 线宽 | 普通和选中边线 1；线性图标 1.3 |
| 字体 | 正文和按钮 13；辅助、时间、标签 11；标题 19；品牌字标 16 |
| 动效 | Hover / Focus 160ms；尊重原有减少动画设置 |

所有值为 egui 逻辑像素，跟随缩放；不引入每帧位图缩放或整窗模糊。媒体原始色彩、字幕用户样式和黑色播放画布不属于界面配色 Token。

## 组件规范

- **按钮**：默认透明弱底、无实体边框；悬停使用抬高表面，键盘聚焦保留清楚的细强调线。图标按钮保留 28×28 点击区域，图形通常 16×16。
- **工具栏**：导航及路径在第一行；第二行按类型筛选、收藏、排序/分组、缩略图尺寸、选择操作分组。组间使用轻分隔和留白；实时性能读数为辅助文字，解释在悬停提示中。
- **媒体卡片**：保留原有排版；选中态不覆盖内容，边线 1px。选择热区 28×28，实际勾选标记 17×17；收藏常驻标记仅小星形，交互时显示轻背景。视频时长标签按文字宽度计算，高 19，辅助字级。
- **播放器**：与主窗口共用图标、表面、边线、文字层级。文件名与目录使用同一小浮层；左右导航只在既有悬停条件下显示，44×64 热区内呈现 32×40 轻控件；音量/全屏使用图标和提示，播放时间在进度条两侧。底部缩略图采用 1px 当前项边线。
- **Popover / 菜单**：共享浮起表面、10px 圆角、1px 边线与轻阴影；菜单项保留图标、文字、右侧快捷键，支持原有键盘操作。
- **Dialog**：共享表面、12px 圆角、20px 内边距。危险确认保持原有人工勾选和确认条件，不弱化错误或危险提示。
- **Toast / 撤回通知**：共享菜单表面，12×9 内边距。短任务沿用轻量状态提示和现有撤回通知；不将错误自动隐藏。撤回期限和提交逻辑不变。
- **Loading / 进度**：媒体占位使用统一辅助字级静态提示，避免几百个单元格各自驱动动画；删除操作显示真实已处理数量和进度条；无法确定百分比的任务保留不定进度提示，不伪造进度。
- **技术信息**：正常扫描结束只显示“媒体库已就绪”，扫描耗时等原始状态保留在悬停提示；CPU/内存/I/O 的口径在性能提示中，诊断细节留在报告文件。真实错误仍可见。

## 状态与行为边界

Hover、Focus、Selected、Disabled 分开表达。不能仅用鼠标悬停表达键盘焦点；不能缩小原有操作热区来换取视觉轻量。收藏、多选、拖选、旋转、回收站/人工永久删除、复制剪切、字幕、轮播、快捷键、窗口拖动与角落关闭均保留。

新增组件应优先复用上述 Token 与状态。需要新的颜色或尺寸时，先在共享组件定义用途；避免在页面里增加无语义的 RGB 或自定义阴影。
