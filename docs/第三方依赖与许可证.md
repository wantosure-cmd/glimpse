## 明确未完成的公开发行事项

1. 应用源码最终许可证由所有者决定；本次未新增应用 LICENSE。
2. libmpv 官方预编译包的完整传递依赖、确切构建脚本、对应源码集；外部 Gyan GPL 构建的全部对应源码及构建配置，尚未整理成满足公开发行要求的源码交付。
3. CRT 许可文本和实际可分发权利确认尚未完成。运行库随本地测试包提供，不据此宣称可任意再分发。
4. LGPL 库虽以 DLL 提供，仍需在公开发行前整理修改/替换/重新链接说明和全部对应源码资料。
5. egui 等 8 个 0.37.0 crate 的 `.cargo_vcs_info.json` 指向的提交 `7c0b40402271e8d40cda69f87cf3c2617c2e4382` 在官方仓库查询返回 404。附带了 eframe 0.37.0 同工作区可获取提交的 MIT/Apache 文本作为参考，`upstream-license-sources.json` 以 `reference_only` 标记；未声称已经核实这些 crate 的完整对应源码来源。

本地测试包附带第三方已有的原许可证，不改写其授权。依赖清单中 “resolved Windows” 是 Cargo 为 Windows 解析到的依赖集合，不等于逐个组件都在最终 exe 中保留了机器码。
