## 必须保留的测量边界

- 首次 UI 回调和输入队列空闲不证明屏幕首帧已经可见且能响应操作；热启动可交互的完整定义尚未证明。
- 未进行三次重启后的系统冷启动，不用应用新缓存替代 OS 冷缓存。
- 回调间隔不是显示器实际呈现时间或 FPS，不能据此宣称实际 60 fps 达标。
- 未测选择目录至首屏媒体可见时间，也未测输入至 seek 新画面的 P95。
- 工作集为采样值，纹理为程序账面值；未记录整个 GPU 驱动的实际总内存。
- 不覆盖真实大摄影图库、集显、Win11、网络盘/CloudDrive 性能或完整目标干净系统。

## 原始证据与复现

- `artifacts/detail-startup.json`：20 次逐次原始时间、PID、包内 CRT 路径。
- `artifacts/p2-scroll-detail-cold4k{,-process,-summary}.json`：新应用缓存的逐回调和逐进程采样。
- `artifacts/p2-scroll-detail-revisit4k{,-process,-summary}.json`：同目录缓存再访。
- `artifacts/detail-browser-idle.json`：30 秒空闲采样。空闲脚本已使用唯一实例作用域，避免转交到用户正在使用的应用。
- `artifacts/detail-performance-verification.json`：核对当前二进制、机器、数据、viewport、阈值及范围。

复现入口为 `tools/measure_local_startup.ps1`、`tools/measure_browser_scroll.ps1`、`tools/measure_browser_idle.ps1` 与 `tools/verify_detail_performance.py`。使用 PowerShell 7；新缓存目录需保持唯一，随后再访和空闲轮复用该目录。生成副本可通过 `tools/make_valid_perf_fixture.ps1` 创建。不要把目录指向真实资源库或为了追求缓存命中而预转码整库。
