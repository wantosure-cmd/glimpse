# 详情浮层与下一项预加载

日期：2026-10-19。Windows 本地测试，保留原生 Rust / egui / libmpv GPU 方案。

## 最终行为

- 取消独占高度的顶部工具栏，媒体画布贴到内容区顶部。左上角使用半透明信息浮层显示返回、文件名、当前序号及所在文件夹；长目录截断，悬停可看完整路径。浮层不推动主布局，拖动文件名可移动窗口。
- 进入详情隐藏系统标题栏及最小化、最大化、关闭按钮；返回列表恢复普通窗口边框。Esc、返回按钮、内容外空白仍可退出详情，Alt+F4 仍是系统关闭方式。
- 右键菜单提供「设置」入口，保留字幕、播放结束策略和快捷键设置；图片旋转、适应和原尺寸仍可在右键菜单使用。左上信息区域也支持右键。
- 当前播放时间在进度条左侧，总时长在右侧，其后是静音、音量与全屏；保持单行，没有常驻播放/暂停按钮。
- 下一张图片通过现有异步解码服务提前准备最高 2048 桶的预览纹理，打开后按需要升级清晰度。沿用文件指纹、任务去重、可见范围调度和全局纹理预算，不无限预解码相册。
- 下一段视频提前只读预热操作系统文件缓存：本地最多头部 4MiB 加尾部 512KiB，已识别的挂载/虚拟路径最多头部 512KiB 加尾部 128KiB；短文件不重复读取。准备当前序列的下一视频，因此也覆盖默认播放结束跳过图片的行为。只设一个延迟创建的工作线程、一个待处理目标；快速切换以最新目标替换等待目标，并按块检查取消。不会创建第二个播放器或提前发声，也不会声称已提前解码完整视频。
- 关闭详情取消预读，回收操作先取消并等待句柄释放；云盘阻塞读取无法保证即时取消，但不在 UI 线程等待，退出应用也不等待该后台读操作。预读失败不阻止正常打开文件，不写回视频/字幕、不另建完整视频缓存。
